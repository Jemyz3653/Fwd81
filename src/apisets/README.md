# src/apisets — заглушки apiset-контрактов (LGPL-2.1-or-later)

Здесь будут генерируемые DLL с именами контрактов Windows 10, которых нет в 8.1:
`api-ms-win-core-*-l1-2-*.dll`, `ext-ms-*`. Внутри — только перенаправления
экспортов на наши `fwd81_*.dll`, своего кода почти нет.

Нужны там, где перехвата загрузчика недостаточно: такие файлы кладутся рядом
с программой. Веха M7.

Пока пусто. Лицензия каталога — LGPL-2.1-or-later.
