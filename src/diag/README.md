# src/diag — анализатор fwd81diag.exe (MIT)

Главный инструмент проекта: читает EXE, вытаскивает список функций, которые тот
берёт из системных библиотек, сверяет со списком «что есть в 8.1» и «что
реализовано у нас», выдаёт вердикт — запустится / запустится с ограничениями /
не запустится.

Веха M1. Без него мы работаем вслепую, поэтому он идёт раньше самого ядра.

Пока пусто. Лицензия каталога — MIT.
