# src/diag — анализатор fwd81diag.exe (MIT)

Главный инструмент проекта: читает EXE, вытаскивает список функций, которые тот
берёт из системных библиотек (обычный импорт и отложенная загрузка), сверяет с
базой «что есть в 8.1 и что реализовано у нас» и выдаёт вердикт — запустится /
запустится с ограничениями / не запустится. Плюс проверяет требуемую версию
Windows из заголовка PE.

Ничего не запускает и не изменяет — только читает файл.

## Как пользоваться

```
fwd81diag [--verbose] <путь-к-программе.exe>
```

Или через общую утилиту (делегирует сюда же): `fwd81cli diag <exe>`.

Коды возврата: 0 запустится, 3 с ограничениями, 4 не запустится, 5 вердикт
невозможен (нет базы 8.1), 1 ошибка аргументов, 2 файл не прочитать.

## Про базу

`fwd81diag_baseline.h` генерирует `exportdiff` (`baseline`). Он закоммичен:
сейчас — в пустом виде (данных 8.1 ещё нет), поэтому вердикт по функциям пока
недоступен и инструмент об этом честно сообщает. Требуемую версию Windows он
показывает уже сейчас. Когда появится копия System32 из 8.1, база
перегенерируется, и вердикт станет полноценным.

Собирается статической CRT + метка подсистемы 6.03 (запуск на самой 8.1),
только x64. Флаг `/bigobj` — потому что с настоящей базой во встроенный
заголовок попадают десятки тысяч имён.
