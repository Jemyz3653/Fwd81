# src/libs — библиотеки реализаций (LGPL-2.1-or-later)

Здесь появятся `fwd81_kernel32.dll`, `fwd81_ntdll.dll`, `fwd81_user32.dll`,
`fwd81_shcore.dll`, `fwd81_bcryptprimitives.dll` — наши версии функций, которых
в Windows 8.1 нет.

Пока пусто: ни одна функция ещё не написана. Первые появятся в вехе M4, и только
те, что реально числятся отсутствующими в `data/missing.json` (его строит
exportdiff в вехе M1). Код «на всякий случай» сюда не кладём.

Каждая функция помечается категорией:

| Категория | Что значит |
|---|---|
| **F** (forward) | тонкая обёртка над функцией, которая в 8.1 уже есть |
| **I** (implement) | настоящая реализация поверх более низкоуровневых функций |
| **S** (stub) | заглушка: корректный код ошибки и запись в журнал |
| **N** (not possible) | на ядре 8.1 невозможно, описывается в docs/limitations.md |

Лицензия каталога — LGPL-2.1-or-later. В шапке каждого файла обязана стоять строка
`SPDX-License-Identifier: LGPL-2.1-or-later`; это проверяет `tools/check_licenses.py`.
