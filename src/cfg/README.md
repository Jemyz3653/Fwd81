# src/cfg — окно настроек fwd81cfg.exe (MIT)

Список профилей программ, галочки возможностей (спуф версии, слой DPI,
логирование, распространение на дочерние процессы), поле «какую версию Windows
сообщать программе», просмотр журналов.

Чистый Win32 + comctl32 версии 6, без .NET новее 4.5 и без WinUI: окно обязано
открываться на самой Windows 8.1. Веха M7.

Пока пусто. Лицензия каталога — MIT.
